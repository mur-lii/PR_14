# PR_14
Описать структуру с именем "Каталог женской одежды", содержащую следующие поля: наименование; артикул; цена; размер; количество.
Написать программу, выполняющую следующие действия: 
- ввод с клавиатуры данных в массив, состоящих из n структур типа Каталог;
- вывод на экран информации о товаре по введенному с клавиатуры артикулу (если такого нет, вывести соответствующее сообщение);
- подсчитать количество товаров определенного размера, введенного с клавиатуры и их общую сумму.
